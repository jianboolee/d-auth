## 一、我们如何收集和使用您的个人信息

我们遵循合法、正当、必要和诚信原则，仅收集为实现以下目的所必需的信息。

### 1. 您主动提供的信息

| 信息类型 | 具体字段 | 处理目的 |
| --- | --- | --- |
| 手机号 | 手机号码 | 注册、登录、身份验证、绑定与找回账号 |
| 邮箱地址 | 邮箱地址 | 注册、登录、密码重置、绑定邮箱 |
| 账号密码 | 密码（**仅以 Argon2id 加盐哈希形式存储，我们不保存明文密码**） | 账号登录与安全验证 |
| 个人资料 | 昵称、头像图片、个人简介、性别 | 展示您的账号信息 |
| 第三方账号信息 | 微信账号的唯一标识（openid / unionid）及其所属应用标识 | 实现微信登录与账号绑定 |

### 2. 您使用服务时我们自动收集的信息

| 信息类型 | 具体字段 | 处理目的 |
| --- | --- | --- |
| 登录日志 | 最近登录时间、最近登录 IP 地址 | 账号安全、异常登录识别 |
| 会话信息 | 登录会话标识、IP 地址、设备与浏览器信息（User-Agent）、会话过期时间 | 维持登录状态、设备管理、安全风控 |
| 操作审计 | 操作类型、操作对象、操作时间、IP 地址、设备信息 | 安全审计、故障排查、履行法律义务 |
| 验证码记录 | 验证码的哈希值（**不存储明文验证码**）、校验尝试次数 | 完成身份验证、防止验证码被暴力猜测 |

### 3. 关于头像图片

您上传的头像图片会存储在我们的对象存储服务（阿里云 OSS）中。**请注意：头像图片的访问链接是公开的，任何获得该链接的人都可以查看该图片。** 请勿上传您不愿公开的图片。

### 4. 关于验证码与限流

为发送验证码、防止短信轰炸与恶意调用，我们会在服务端缓存中以您的**手机号或邮箱地址**作为键名，短期记录验证码哈希、发送时间与发送次数。这些记录的有效期很短（验证码与发送间隔通常为 5 分钟以内，小时级计数不超过 1 小时），到期后自动删除。

### 5. 我们不会收集的信息

我们**不收集**您的身份证件号码、生物识别信息、精确地理位置、通讯录、相册（除您主动上传的头像外）等与实现服务目的无关的信息。

## 二、我们如何使用您的个人信息

我们将收集的信息用于下列用途：

1. **提供账号服务**：完成注册、登录、身份验证、资料展示与账号管理；
2. **保障账号与系统安全**：识别异常登录、防止欺诈、撞库、短信轰炸等滥用行为，进行必要的安全审计；
3. **发送必要的通知**：向您发送验证码，以及账号安全相关的必要通知；
4. **履行法律义务**：按法律法规或主管部门要求留存必要记录、配合调查；
5. **改进服务**：以统计方式分析服务运行状况（我们不进行用于广告投放的用户画像）。

**我们不会将您的个人信息用于本政策未载明的其他目的。** 如需超出本政策范围使用，我们将再次征得您的同意。

## 三、Cookie 与本地存储

1. **会话 Cookie。** 为维持您的登录状态，我们会在您的浏览器中写入一个会话标识 Cookie（名称通常为 `dauth_session`）。该 Cookie 设置了 `HttpOnly` 属性（网页脚本无法读取），并设置了 `SameSite` 属性以降低跨站请求伪造风险；默认有效期为 30 天。该 Cookie 仅保存一个随机会话标识，不包含您的手机号、邮箱或密码。
2. **本地存储。** 若接入应用使用客户端令牌方式（常见于 App、小程序），相关凭据可能保存在您设备的本地存储中，用于免密续期。您可通过退出登录清除这些凭据。
3. 您可以通过浏览器设置清除或拒绝 Cookie，但这将导致您无法保持登录状态。

为进行用户支持、账号问题排查与安全管理，我们的授权管理人员与持有相应权限的接口调用方可以查看您的完整手机号或邮箱地址。我们会通过权限分级、操作审计等措施约束此类访问。

### 4. 法律要求

出现下列情形时，我们可能依法对外提供您的个人信息：

- 与国家安全、国防安全直接相关的；
- 与公共安全、公共卫生、重大公共利益直接相关的；
- 与犯罪侦查、起诉、审判和判决执行等直接相关的；
- 为维护您或其他个人的生命、财产等重大合法权益且难以取得本人同意的；
- 依照法律法规或主管部门强制性要求提供的。

## 五、个人信息的存储

1. **存储地点。** 您的个人信息存储于**中华人民共和国境内**的服务器。默认情况下，我们不会将境内收集的个人信息传输至境外。如确需跨境传输，我们将依法履行相应的安全评估或备案程序，并单独征得您的同意。
2. **存储期限。** 我们仅在实现处理目的所必需的期限内保留您的个人信息：

| 信息类型 | 保存期限 |
| --- | --- |
| 验证码及其发送记录 | 5 分钟至 1 小时，到期自动删除 |
| 账号资料、登录凭据 | 自账号创建至您注销账号为止 |
| 登录会话记录 | 自最后一次活跃起保存 30 天（持续使用会顺延，即长期不登录才失效），或被您主动退出/撤销时终止；失效后的记录不再用于登录，并按内部策略清理 |
| 操作审计日志 | 为满足安全审计与法律义务，在法定或内部规定的期限内保留；超过期限后删除或匿名化处理 |

3. **注销后的处理。** 您注销账号后，我们将删除或匿名化处理您的个人信息，法律法规另有规定或为实现合规目的确需保留的除外。

## 六、我们如何保护您的个人信息

我们采取符合业界标准的安全措施保护您的信息，包括：

1. **传输安全**：通过 HTTPS 加密传输您的信息；
2. **密码安全**：密码采用带随机盐的 Argon2id 算法哈希后存储，我们无法还原您的明文密码；
3. **凭据保护**：会话 Cookie 设置 `HttpOnly` 属性，防止脚本窃取；刷新令牌在校验时比对的是哈希值而非明文；
4. **访问控制**：内部按最小必要原则分配权限，管理操作留有审计记录；
5. **安全审计**：记录关键操作与异常行为，用于发现和处置安全事件；
6. **验证码防滥用**：对验证码的发送与校验实施频率限制和尝试次数限制。

**请您理解，互联网环境并非绝对安全。** 请妥善保管您的账号、密码与验证码，不要向他人透露。若发生个人信息安全事件，我们将依法及时告知您并向主管部门报告。

## 七、您的权利

依照法律法规，您对您的个人信息享有下列权利：

1. **查阅与复制**：您可以在账号设置中查看您的资料、绑定方式与登录设备，也可通过本政策末尾的联系方式申请获取您的个人信息副本。
2. **更正与补充**：您可以自行修改昵称、头像、简介、性别等资料，或通过身份验证更换绑定的手机号与邮箱。发现信息有误的，也可联系我们更正。
3. **删除**：在下列情形下，您可以要求我们删除您的个人信息：处理目的已实现或为实现目的不再必要；我们停止提供产品或服务；您撤回同意；我们违反法律法规或与您的约定处理您的信息。
4. **注销账号**：您可以申请注销账号。注销完成后，我们将按本政策第五条的约定处理您的个人信息。**注销后账号不可恢复，且该手机号/邮箱可能无法再次用于注册。请在注销前自行备份需要保留的内容。**
5. **撤回同意**：您可以通过关闭相应功能授权或联系我们撤回此前的同意。撤回同意不影响撤回前基于同意已进行的处理活动。
6. **解释说明**：您有权要求我们对个人信息处理规则进行解释说明。
7. **投诉举报**：您认为我们的处理行为侵犯了您的合法权益的，可通过本政策末尾的联系方式投诉，也可向网信、市场监管等主管部门反映。

为保障安全，我们在响应您的请求前可能需要验证您的身份。我们将在收到请求后【15】个工作日内予以响应。

## 八、未成年人

本服务主要面向成年人。**我们原则上不向未满 14 周岁的儿童提供服务。** 若您未满 14 周岁，请在监护人陪同下阅读本政策，并在取得监护人同意后使用本服务。我们若发现在未取得监护人同意的情况下收集了儿童个人信息，将依法删除。若您是儿童的监护人，对其个人信息有疑问，可通过本政策末尾的方式联系我们。
